# Worklog 2026-08-28 (fuel gauge, HUD, Docker, Adreno 3D)

Xiaomi Mi 5 (**gemini**). Baseline: Linux **7.0** + Ubuntu **26.04** on userdata + framebuffer HUD. Serials and LAN IPs omitted. Password file is gitignored and is not written here.

## Rules that stayed

Do not flash userdata. Do not flash ginkgo dtbo/vbmeta. GDM stays masked. HUD hot-replace is lost on reboot until you flash boot.

## Fuel gauge / power

Mainline 7.0 `pmi8994.dtsi` had no fuel-gauge/smbchg. 6.1 had `qcom-battery`. Local overlay adds `qcom_fg` / `qcom-smbchg` and a `simple-battery` node. HUD reads `capacity` + `status` every second; `current_now` is too slow for the hot path (QPNP ADC).

## Docker

Installed on the phone from Ubuntu ports. Engine works; keep it off the display path.

## Adreno 3D

Vendor-signed zap firmware. Freedreno FD530 / GLES 3.1. HUD prefers GBM + EGL + GLES2; CPU `write(/dev/fb0)` is fallback.

## Reboot to fastboot

Short Volume Up on the HUD (no Power). Success is USB `18d1:d00d`. Writing `reboot-fastboot` into ACM races getty.
