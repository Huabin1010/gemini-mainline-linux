# Worklog 2026-08-30 (blank suspend, white cluster, ghost touch)

Xiaomi Mi 5 (**gemini**, MSM8996). Linux **7.0** + Ubuntu **26.04** on userdata + `gemini-status` HUD. Flashed to **boot** the same day. GitHub **[v0.2.0](https://github.com/Huabin1010/gemini-mainline-linux/releases/tag/v0.2.0)** is boot-only — do **not** flash userdata.

Earlier scanout: [display-and-reboot-fastboot-7.0.md](display-and-reboot-fastboot-7.0.md). HUD Wi-Fi: [worklog-2026-08-29.md](worklog-2026-08-29.md).

## Goals (all done)

1. Unblank: no right-edge **white line cluster**.
2. Unblank: no jumping / ghost touch (even with no finger).
3. Blank really turns the glass off (DCS `0x28`), not only WLED.
4. Blank runtime-suspends **GPU / DSI / MDP** (GFX, DSI PLL, MDP clocks gated).

`scripts/check-blank-power.sh` covers sysfs / dmesg / FG. White bars are visual; confirmed on glass.

## Hardware (do not re-guess)

JDI FHD R63452 command mode. Working `0x0A` is **`0x38`** (not ginkgo `0x9c`); after `0x28` it is **`0x30`**. ID `0xBF` = `02 3c 34 52`. Synaptics **S3330 incell** shares analog with the panel. Keep `MIPI_DSI_CLOCK_NON_CONTINUOUS`.

| Do not | Result |
|--------|--------|
| Write `0xec … 0x95` on blank | Drops incell AVDD; S3330 I2C `-6`; `event3` gone until GPIO reset (more white lines) |
| GPIO-reset the panel on every unblank | Right-edge white cluster |
| Power down 14nm PHY then DCS **`0x11`** | White cluster; `0x18` → `0x38` |
| `rmmod msm` | oops |
| Treat `fastboot reboot` as the last `fastboot boot` ramdisk | It boots the **partition** |

The old visually-clean blank kept the PHY up and only sent `0x28`/`0x29` (~**2.4 W**, no suspend). Full PHY off + `0x11` on resume gated clocks (~**1.9 W**) and painted white bars. `0x29` without `0x11` after PHY down stays at `0x18`.

## What shipped

Blank: WLED 0, `gpu_runtime_pin(0)`, gold CPU2/3 offline, DCS **`0x28` only**, then `SetCrtc(fb=0)`. Host **gates link clocks** and `pm_runtime_put`. Skip `regulator_bulk_disable` and `phy_disable`. PHY `CMN_CTRL_0` stays **`0xff`** while GPU/DSI/MDP are `suspended`.

Unblank: modeset last GBM fb; `enable()` if already inited sends **`0x29` only** (no `0x11`, no GPIO). Warmup frames, then WLED. Ignore touch-wake for ~3 s after blank (`t_blank`). Drop `clk_ignore_unused pd_ignore_unused` from cmdline so unused clocks can gate.

## Power (PMI8994 FG, noisy ±0.2–0.4 W)

| State | Median | Notes |
|-------|--------|--------|
| Screen on | **~3.3–3.8 W** | `0x38`, clocks on |
| Off, lamp only (old) | ~**2.4 W** | DSI still scanning |
| Off, PHY fully down | ~**1.9 W** | White bars |
| Off, **current** (clocks gated, analog kept) | **~2.19 W** | ~**1.3 W** below on; residual is Wi-Fi / USB gadget / Ubuntu / PHY analog, not scanout |
